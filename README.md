# Barcelos — интерактивная 3D-карта

Трёхмерная карта Барселуша (Португалия) в браузере: настоящий рельеф, светящаяся сеть улиц, дома города, леса, парки и река Каваду из OpenStreetMap, плюс процедурные модели достопримечательностей в реальном масштабе. Нажмите на метку или строку в списке: камера подлетит к месту, справа откроется карточка с фото и описанием.

Проект — отдельный форк движка [braga-3d](https://github.com/isatimur/braga-3d): тот же код, свои данные, модели, тексты и характер города. Стек: Vite и three.js, чистый JavaScript без фреймворка.

## Состояние

Это первый раунд: скелет проекта и конфиг города. Данные OSM (рельеф, дороги, здания, природа) собираются пайплайном из `scripts/`. Модели пока — общая «масса» по контурам OSM; детальные модели, тексты, фото, маршруты и кино — следующие раунды.

| Что | Где | Состояние |
| --- | --- | --- |
| Конфиг города | `cities/barcelos.json` | готов: центр, ядро и кольцо, 19 кандидатов в места |
| Движок | `src/`, `scripts/`, `api/` | скопирован из braga-3d, дефолтный город — barcelos |
| Данные | `data/` | собирает `npm run city -- barcelos` |
| Модели | `src/models/barcelos/` | общая масса; детальные по одному |
| Тексты | `src/locales/` | пока только общий `ui.js` |
| Домены | `barcelos-3d.com` (ждёт деплой) | – |

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev      # сервер разработки, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр собранной версии
```

## Данные

```bash
npm run city -- barcelos --dry-run     # что будет скачано
npm run city -- barcelos               # рельеф, здания, MS-здания, дороги, природа, тайлы, оси трафика
node scripts/check-geo.mjs             # проверка контуров, домов и рельефа
```

Каждый шаг идёт через `--city barcelos` и читает всё из `cities/barcelos.json`. Кольцевые тайлы Overpass качаются долго: запускать ночью, `--from tiles` для возобновления.

## Отличия Барселуша

- Каваду и средневековый мост 1325–1328 годов — главный вид города, вода по скиллу `3d-ultra-realistic-water`.
- Петух Барселуша как символ проекта (иконка, шаринг, «характер»).
- Барочный Бон-Жезуш-да-Круш на Campo da Feira, дворец графов, коллегиальная церковь, музей гончарства — ядро списка мест.
- Город ЮНЕСКО в сети Creative Cities (ремесло и народное искусство).

## Движок общий с braga-3d

`src/` (кроме `src/models/barcelos/`) и `scripts/` — общий движок. Обновления переносятся вручную/cherry-pick из braga-3d. Детали многогородского движка — в `cities/README.md` braga-3d.

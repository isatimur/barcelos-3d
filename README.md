# Barcelos — интерактивная 3D-карта

Трёхмерная карта Барселуша (Португалия) в браузере: настоящий рельеф, светящаяся сеть улиц, дома города и окрестностей, леса, парки и река Каваду из OpenStreetMap, плюс 14 достопримечательностей с процедурными моделями в реальном масштабе и фотографиями. Нажмите на метку или строку в списке — камера подлетит к месту, справа откроется карточка.

Карта открывается «золотым часом». Время суток меняется (утро · день · закат · ночь), ночью горят окна домов и фонари. Есть кино о городе (14 глав), рассказ «Город в пяти местах», три пеших маршрута и режим «Сейчас».

Проект — отдельный форк движка [braga-3d](https://github.com/isatimur/braga-3d): тот же код, свои данные, модели, тексты и характер города. Стек: Vite и three.js, чистый JavaScript без фреймворка.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm test         # проверки выбора города
```

## Данные

```bash
npm run city -- barcelos --dry-run     # что будет скачано
npm run city -- barcelos               # рельеф, здания, MS-здания, дороги, природа, тайлы, оси
node scripts/check-geo.mjs             # контуры, дома, рельеф
node scripts/check-dimensions.mjs      # размеры мест
node scripts/check-fit.mjs             # модели встали 1:1 на контуры
node scripts/fetch-pois.mjs            # кафе, магазины, улицы, площади, скамейки
node scripts/fetch-ms-buildings.mjs --fetch && node scripts/fetch-ms-buildings.mjs --build
node scripts/make-og.mjs --pages --og --icons   # страницы, og, иконки (нужен dev-сервер)
```

Ширина реки Каваду задаётся в конфиге (`nature.line_widths: { river: 60 }`), поэтому пайплайн воспроизводит широкую воду. Кино-порядок и стартовый вид тоже в конфиге (`cinema_order`, `start_view.home`).

## Отличия Барселуша

- **Каваду и средневековый мост** (1325–1330, пять арок) — главный вид города; карта открывается именно на нём.
- **Петух Барселуша** — символ проекта (иконка, шаринг).
- **Бон-Жезуш-да-Круш** на Campo da Feira, дворец графов, коллегиальная церковь, музей гончарства, башня Порта-Нова, стадион «Сидаде де Барселуш».
- Город ЮНЕСКО в сети Creative Cities (ремесло и народное искусство).

## Проверки в браузере

`window.__braga` даёт доступ ко всему: `stats` (вызовы отрисовки, треугольники, здания, деревья), `cinema.audit()`, `story.seek(n)`, `landmarksRealScale()`. Параметры адреса: `?intro=0`, `?fx=1`, `?quality=low`, `#place=<id>`, `#time=night`, `#cinema`, `#story`.

Обзор города: около 150 вызовов отрисовки и 1,4 млн треугольников за кадр вместе с тенями и эффектами; зданий Microsoft в ядре 17 365, кольцо грузится по мере приближения. Когда вкладка скрыта, цикл отрисовки стоит.

## Движок общий с braga-3d

`src/` (кроме `src/models/barcelos/`) и `scripts/` — общий движок. Обновления переносятся cherry-pick из braga-3d.
